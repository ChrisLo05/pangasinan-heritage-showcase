STEP-BY-STEP DEPLOYMENT PROCESS:

--------------------------------------------------------------------------------
STEP 1: Build the Static Site (2 minutes)
--------------------------------------------------------------------------------

Open terminal in this folder and run:

    npm run build

This creates the 'out/' folder with your static files.

--------------------------------------------------------------------------------
STEP 2: Create GitHub Repository (3 minutes)
--------------------------------------------------------------------------------

1. Go to: https://github.com/new

2. Fill in:
   - Repository name: pangasinan-heritage-showcase
   - Description: "Pangasinan Heritage Digital Showcase - Activity 2"
   - Visibility: PUBLIC (important!)
   - Do NOT check "Initialize with README"

3. Click "Create repository"

4. Copy the repository URL (example):
   https://github.com/YOUR-USERNAME/pangasinan-heritage-showcase.git

--------------------------------------------------------------------------------
STEP 3: Push Code to GitHub (5 minutes)
--------------------------------------------------------------------------------

Run these commands in terminal (in this folder):

    git init
    git add .
    git commit -m "Activity 2 - Initial deployment"
    git remote add origin https://github.com/YOUR-USERNAME/pangasinan-heritage-showcase.git
    git branch -M main
    git push -u origin main

Replace YOUR-USERNAME with your actual GitHub username!

--------------------------------------------------------------------------------
STEP 4: Enable GitHub Pages (2 minutes)
--------------------------------------------------------------------------------

1. Go to your repository on GitHub
2. Click "Settings" tab
3. Click "Pages" in left sidebar
4. Under "Build and deployment":
   - Source: Select "GitHub Actions"
5. Done! The site will deploy automatically

Wait 2-5 minutes for deployment to complete.

--------------------------------------------------------------------------------
STEP 5: Get Your Live URL
--------------------------------------------------------------------------------

Your website will be at:

    https://YOUR-USERNAME.github.io/pangasinan-heritage-showcase/

Open it in your browser and test!

--------------------------------------------------------------------------------
STEP 6: Run Lighthouse Audit (5 minutes)
--------------------------------------------------------------------------------

1. Open your live site in Google Chrome
2. Right-click → Inspect
3. Click "Lighthouse" tab
4. Check: Performance, Accessibility, Best Practices, SEO
5. Click "Analyze page load"
6. Wait for results
7. Screenshot the results

--------------------------------------------------------------------------------
STEP 7: Submit to Google Classroom
--------------------------------------------------------------------------------

Submit these 3 items:

1. GitHub Repository Link:
   https://github.com/YOUR-USERNAME/pangasinan-heritage-showcase

2. GitHub Pages Link:
   https://YOUR-USERNAME.github.io/pangasinan-heritage-showcase/

3. Lighthouse Results:
   Upload your screenshot or PDF

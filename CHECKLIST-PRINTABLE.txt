TROUBLESHOOTING:
================================================================================

"npm not recognized" → Install Node.js from https://nodejs.org/ then restart CMD

"git not recognized" → Install Git from https://git-scm.com/download/win

Can't push to GitHub → Use Personal Access Token instead of password
                       Go to: https://github.com/settings/tokens

404 on GitHub Pages → Wait 2-5 minutes, refresh page

Build fails → Delete node_modules, .next, out folders
              Run: npm install
              Run: npm run build
